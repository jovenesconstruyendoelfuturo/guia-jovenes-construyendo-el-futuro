# Verificador de Requisitos - Jóvenes Construyendo el Futuro

Herramienta web interactiva y guía informativa independiente diseñada para ayudar a las personas interesadas en el programa social "Jóvenes Construyendo el Futuro" a comprobar rápidamente si cumplen con los requisitos básicos iniciales (edad y situación ocupacional).

## Aviso Legal y Exención de Responsabilidad

> Este sitio es una guía informativa independiente. No es el sitio oficial del programa ni pertenece al Gobierno de México ni a la STPS. La plataforma oficial es: jovenesconstruyendoelfuturo.stps.gob.mx

Plataforma oficial: https://jovenesconstruyendoelfuturo.stps.gob.mx/

Todos los trámites, registros y convocatorias oficiales deben validarse y realizarse exclusivamente a través de los canales institucionales del Gobierno de México.

## Contenido del Proyecto

- **Verificador interactivo en JavaScript:** Permite evaluar de manera orientativa y sin fines vinculantes si el usuario cumple con el rango de edad (18 a 29 años) y el estado ocupacional (no estudiar ni trabajar).
- **Guía explicativa del programa:** Resumen claro sobre qué es el programa, cómo funciona la vinculación en centros de trabajo, cómo recuperar el acceso a la plataforma oficial y recomendaciones para evitar estafas.
- **Preguntas frecuentes (FAQ):** Respuestas a dudas comunes sobre gratuidad, duración de la capacitación, apoyos otorgados y cambios de centro laboral.
- **Prevención de fraudes:** Pautas de seguridad para identificar el portal oficial y no compartir contraseñas ni realizar pagos a gestores o intermediarios.

Para obtener orientación detallada, guías paso a paso y resolver inquietudes sobre el registro, consulta la [guía informativa independiente de Jóvenes Construyendo el Futuro](https://jovenesconstruyendoelfuturoguia.com.mx/).

## Características Técnicas

- **Tecnologías:** HTML5 semántico, CSS3 puro y JavaScript vanilla (sin frameworks ni dependencias externas).
- **Rendimiento y Privacidad:** Sin scripts de seguimiento, sin publicidad y optimizado para una carga ultrarrápida.
- **Accesibilidad y Diseño:** Totalmente responsivo para dispositivos móviles y computadoras, con alto contraste y soporte de navegación accesible.

## Ejecución Local

Para visualizar el sitio localmente, clona el repositorio y abre `index.html` en cualquier navegador web moderno, o sírvelo con cualquier servidor HTTP local:

```bash
# Con Python 3
python -m http.server 8000
```
